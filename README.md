# Loan Approval Prediction System

## Problem
This project predicts whether a loan should be approved or rejected based on applicant details.
In this project kaggle dataset is used for creating model.

## Features Used
- Number of Dependents
- Education
- Self Employed
- Income
- Loan Amount
- Loan Term
- CIBIL Score
- Assets (Residential, Commercial, Luxury, Bank)

## Model Used
Random Forest Classifier

## Accuracy
97.65

## How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Run test file:
python test.py

## Output
Loan Approved / Loan Rejected
