# Loan Approval Prediction System

## Problem Statement
This project predicts whether a loan application should be approved or rejected based on applicant details and financial information. The model is trained using a Kaggle dataset and helps automate the loan approval decision-making process.

## Features Used
* Number of Dependents
* Education
* Self-Employed Status
* Applicant Income
* Loan Amount
* Loan Term
* CIBIL Score
* Residential Assets Value
* Commercial Assets Value
* Luxury Assets Value
* Bank Assets Value

## Model Used
* Random Forest Classifier

## Model Performance
* Accuracy: 97.65%

## Technologies Used
* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib

## Dataset
The dataset used for training and testing the model was obtained from Kaggle.

## How to Run
1. Install the required dependencies:
```bash
pip install -r requirements.txt
```
2. Run the test file:
```bash
python test.py
```

## Output
The model predicts one of the following outcomes:
* Loan Approved
* Loan Rejected
